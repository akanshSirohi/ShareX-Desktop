# ShareX Desktop website showcase

Captured 18 October 2026 from ShareX Desktop v0.1.3.

- `screenshots/`: ten clean PNG captures, 2880 × 1574 pixels (2× display scale).
- `website/`: lossless WebP versions, plus framed dark and light hero images.
- `preview.png`: a contact sheet of nine selected screens.
- `index.html`: a local gallery with links to full-resolution captures.
- `manifest.json`: image dimensions, descriptions, and suggested alt text.

Use `website/hero-dark.webp` or `website/hero-light.webp` for a homepage hero. Use the individual WebP images in feature sections, retaining their aspect ratio. Keep the PNG originals for future exports. The hero canvases are 2400 × 1520 pixels.

These are actual native app screens with controlled sample files in an isolated showcase profile. Transfer entries came from three real local downloads and two real local uploads. The plugin catalog is real. Storage choices were displayed without changing the shared root to all drives. The browser record belongs to a local showcase browser. LAN addresses and QR codes show the captured session, which was stopped after capture.

The original ShareX logo is used throughout. Framed hero images add only a presentation background and window frame around an unmodified app capture. The sidebar spacing and theme-aware scrollbars were corrected before final capture.
