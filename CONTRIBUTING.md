# Contributing

Issues and pull requests are welcome. Read the [build guide](docs/building.md), [architecture](docs/architecture.md), and [development checks](docs/development.md) before making changes.

Keep changes focused. Explain the problem, the resulting behavior, and how you tested it. Include screenshots for interface changes and the operating system for platform-specific fixes. Use disposable sample files and documentation addresses; do not commit personal paths, runtime state, credentials, or private network captures.

Run the checks relevant to your change. Update documentation when behavior or setup changes. Portal changes should include both `portal-source/` edits and the regenerated `src-tauri/portal/` export. Preserve the original ShareX branding, attribution, and dependency license notices.

Report Android-only issues in [ShareX Android](https://github.com/akanshSirohi/ShareX). Report vulnerabilities privately using [SECURITY.md](SECURITY.md). Contributions are provided under this repository's AGPL-3.0-or-later license.
