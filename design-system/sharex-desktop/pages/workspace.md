# Desktop workspace override

The operational desktop workspace overrides the generated landing-page pattern and gold palette in MASTER.md.

- Use three regions: persistent navigation, primary file workspace, and session inspector.
- Use Segoe UI Variable with Segoe UI/system fallbacks. Limit typography to one interface family and a monospace family for addresses and previews.
- Dark colors: background `#101014`, sidebar `#151519`, surface `#19191f`, borders `#292830`, primary text `#e9e8ee`, secondary text `#92909e`, quiet text `#85818f`.
- Accent: violet `#a995fa`, primary action fill `#b5a2ff`. Green indicates active connection status only; red indicates errors or destructive actions.
- Use the original ShareX logo from the Android project's web assets. Do not create an alternative brand mark.
- Keep the hexagonal pattern inside the connection illustration. File lists and settings remain quiet, flat, and readable.
- Use a semantic table, native checkboxes, labeled buttons, visible focus, short transitions, and reduced-motion support.
- Read-only mode and root scope must remain visible. Do not invent files, devices, speeds, addresses, or sharing status.
- Use utility copy. Empty states explain the next available action. Modal validation stays visible inside the dialog.

See `docs/DESIGN.md` for the visual and interaction thesis.
